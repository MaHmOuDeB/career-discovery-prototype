# Held-out vacancy set
All 24 vacancies and companies are fictional, written for the German market on 2026-11-17.
They were written without access to the matcher vocabulary (analysis.py, catalog.json, .state/).
Purpose: measure coverage and precision on text that is independent of the matcher's own wording.
Format: see "Held-out evaluation set" in docs/handoff/diagnostics/2026-11-17-coverage-gap.md.
