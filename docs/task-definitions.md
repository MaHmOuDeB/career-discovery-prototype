# Task definitions

The matcher compares the work a vacancy describes with the work a candidate's reviewed evidence shows. Each
catalogue task below is a kind of work, independent of job title. Labellers and reviewers use these definitions;
the matching vocabulary lives in `career_discovery/catalog.json` and `career_discovery/analysis.py`.

| Task | The work |
| --- | --- |
| troubleshoot | Diagnose and resolve user, customer, technical or operational problems: support tickets, escalated cases, errors, incidents, root-cause analysis. |
| triage | Assess, prioritise, route or escalate incoming issues, requests or incidents. |
| onboard | Get new customers, users or clients set up and productive with a product or service. |
| configuration | Set up or configure software, accounts, product settings or system parameters for users or customers. |
| systems_integration | Connect systems via APIs, interfaces or integrations, and fix data exchange between them. |
| document_process | Write or maintain process documentation, runbooks, guides, SOPs, knowledge-base articles or records of how work is done. |
| reconcile | Compare records and investigate or resolve discrepancies or exceptions. |
| spreadsheets | Work in Excel, Google Sheets or similar spreadsheet tools. |
| report_kpis | Track, monitor or report KPIs and operational, business or quality metrics. |
| metric_design | Define or design KPIs, success metrics or measurement frameworks. |
| dashboard | Build or maintain dashboards and data visualisations (Tableau, Power BI, Looker and similar). |
| sql | Write SQL or query relational databases. |
| pipeline | Build or run ETL processes or data pipelines. |
| automate | Automate workflows, reports, processes or manual tasks. |
| data_analysis | Analyse data or datasets to find patterns, causes or insights. |
| data_quality | Validate, clean, audit or maintain the accuracy of data and records. |
| experiment | Design, run or analyse experiments and A/B tests. |
| evaluate_systems | Evaluate or benchmark the outputs or performance of models, systems or workflows. |
| develop_learning | Design or develop training material, courses, curricula, learning modules or assessments. |
| lms | Work with a learning management system. |
| teach | Teach, train or run workshops and training sessions for customers, users, staff or students. |
| authoring | Use e-learning authoring tools. |
| clinical_documentation | Clinical or care documentation, patient records, EHR systems. |
| stakeholders | Coordinate or communicate with stakeholders, partners or cross-functional teams. |
| sales | Sell, prospect, run sales cycles or manage pipeline and accounts for revenue. |
| inventory | Manage stock, inventory or materials planning. |

A duty line can name several tasks or none. A duty describes work done in the role ("Resolve escalated tickets").
A qualification describes what the candidate must or should bring ("2+ years of experience with SQL",
"Fluent German, C1"). A qualification is not a duty even when it appears under a duties heading.
