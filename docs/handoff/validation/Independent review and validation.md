# Career Discovery Prototype independent review

17 November 2026

Two independent reviewers evaluated the German-market CLI in sequence. The first found seven issues. The second reran 12 targeted tests covering the first fixes, reviewed the original implementation and remediation, and found five additional cases. The main session applied the fixes from both reports.

## What changed

| Area | Result |
| --- | --- |
| Mandatory requirements | The parser separates optional language levels from minimum levels and retains explicit candidate conditions in additional information. Unresolved conditions get a review finding, including a clearance requirement attached to an otherwise satisfied tool requirement. A recorded conflict still excludes the job. |
| Experience and seniority | Scoped tenure uses the candidate’s months for the relevant skill. Shared alternatives keep their duration operator. Early-career candidates see seniority and ownership uncertainties in both ranking modes. An exact reviewed requirement or vacancy-specific scope check can resolve applicable uncertainty. |
| Evidence and ranking | Vendor implementation, proposal content and hypothetical work do not provide direct evidence of the candidate implementing the task. Coordinated duties and separate bullet points score alike for the reproduced cases. Repeating one supported capability does not create a strong fit. |
| Application verification | Automatic verification requires recent employer-feed membership, the exact vacancy URL, a matching heading and an enabled application control. Explicit closure takes precedence. Unsupported automatic requests preserve applicable manual decisions, and older automatic checks using the weaker rule require rechecking. |
| Blind pilot | Both methods contribute up to five review-first cases as well as actionable results. Ratings coverage is visible for each lane. Rates stay undefined when no relevant labels exist, and fully labelled corpora can show missed relevant vacancies. |

## Verification results

- **63 offline tests passed**, covering the two sets of review findings and the CLI flow from profile import, review and search through the blind pilot pack, scoring, export and deletion.
- The 26-case public benchmark contains **5 confirmed application controls, 19 unverified application paths and 2 expired controls**. The final pass used 27 bounded public HTTP GETs including robots checks. The verification window is 24 hours.
- The four fictional scenario profiles produced 96 profile and vacancy pairs. Task matching found 12 relevant results in 18 filled actionable slots. The title baseline found 5 in 10. These are designed controls with unequal filled-slot counts.
- The private replay used the authorised English CV locally with provisional Berlin preferences and fixed clocks for both corpora. The saved profile remained unconfirmed. Paid API spend was **$0**.

## Validation still open

- The original 12-board supply observation on 16 November screened 1,181 listings into one plausible review case and zero actionable matches. It fell short of the target of ten plausible openings across three employers and two role families. A comparable second observation is due around **23 November**. Reanalysis at the first observation’s original time preserves the comparison settings.
- The candidate still needs to review the private profile. The anonymous benchmark has 26 blank ratings with independent fields for relevance, realism, conflict and availability. The subsequent explanation audit checks each claim against the employer’s wording and candidate evidence.
- The planned evaluation with three to five consenting volunteers remains open. Useful adjacent discoveries, time to find three viable jobs, observed reuse, actionable-link quality and explanation accuracy still need measurements.
